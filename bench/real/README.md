# bench/real — tier R: real, field-collected RTL bugs (docs D6)

14 bugs in 11 production open-source designs, imported by
`scripts/import_rtlrepair.py` from RTL-Repair's `benchmarks/fpga-debugging`
(https://github.com/ekiwi/rtl-repair, BSD-3 packaging), which derived them
from the 20 executable bugs of *Debugging in the Brave New World of
Reconfigurable Hardware* (ASPLOS'22). Designs and their upstream licenses:
alexforencich `verilog-axis` cores (MIT), Xilinx AXI-Lite/AXI-Stream
template IP (`xlnxdemo`, `xlnxstream_2018_3`), ZipCPU `sdspi` (GPLv3),
`fadd`. Redistributed here for benchmark reproduction only; cite upstream.

Per bug: `design.json` (sources, top, bug file, tables, provenance),
`rtl/` golden, `rtl_buggy/` (same file list, one file replaced), `tb/*.csv`
table testbenches (one row per rising edge; inputs driven, outputs checked
pre-edge), `tb_table.cpp` (generated by `scripts/gen_table_tb.py`), and
`bug.diff` (upstream golden -> buggy).

Gate and labels: `scripts/validate_real.py` -> `bench/kill_matrix_real.json`
(golden passes, buggy killed, 14/14); `scripts/gen_real_labels.py` ->
`bench/causal_labels/real/` (first-divergence causal ground truth).
Run with the driver: `--mutants-dir bench/real`.
